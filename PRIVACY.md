# Политика конфиденциальности приложения «Деберц»

_Последнее обновление: 29 сентября 2026 г._

Приложение «Деберц» — офлайн-игра в карты против компьютера.

**Мы не собираем никаких данных.**

- Приложение не требует регистрации и не запрашивает почту, телефон или другие контактные данные.
- В настройках можно указать своё имя — это необязательно. Имя нужно только для подписи за игровым столом, хранится на этом устройстве и никуда не передаётся — разве что вы сами отправите файл «Сообщить о проблеме» (о нём ниже).
- Настройки, сохранённая партия и статистика игр тоже хранятся только на устройстве.
- Приложение не подключается к интернету, не показывает рекламу, не использует аналитику и сторонние SDK.
- Не ведётся отслеживание (tracking) пользователей.
- Данные приложения попадают в резервную копию устройства (iCloud или на компьютере) вместе с данными других приложений — это обычный механизм iOS, доступ к копии есть только у владельца. При удалении приложения его данные удаляются с устройства.

**Файл «Сообщить о проблеме».** В настройках (а в тестовых сборках — ещё в меню и в итогах сдачи) есть ссылка «Сообщить о проблеме». Файл для неё готовится на устройстве, а отправляет его только сам пользователь: нажатие открывает стандартное меню «Поделиться», и пользователь сам выбирает, куда и кому его отправить (почта, мессенджер и т. п.). Без этого файл никуда не уходит. Внутри — настройки приложения (включая имя, если оно задано), ход партии (карты, взятки, счёт), версия приложения, модель устройства и версия iOS. Разработчик использует присланный файл только для того, чтобы разобраться с проблемой.

При тестировании через TestFlight компания Apple может передавать разработчику технические сведения о сбоях и отзывы, которые вы сами отправляете через приложение TestFlight. Это регулируется [политикой Apple для TestFlight](https://www.apple.com/legal/privacy/data/ru/test-flight/).

# Privacy Policy — "Деберц" (Deberc)

The app is an offline card game played against the computer. **It collects no data.** It has no accounts, network access, ads, analytics or third-party SDKs, and does no tracking. The optional player name in Settings is used only as a label at the game table; it stays on the device and is never sent anywhere, unless you send a problem report yourself (see below). Settings, the saved game and game statistics also stay on the device. Like any app data, they are included in the device's own backup (iCloud or computer), which only the owner can access, and they are removed from the device when the app is deleted. TestFlight crash reports and feedback you choose to send are handled by Apple under its TestFlight privacy terms.

**Problem report file.** Settings (and, in test builds, also the main menu and the deal summary) contain a "Сообщить о проблеме" (Report a problem) link. The report file is prepared on the device and is sent only by you: tapping the link opens the standard Share sheet, and you choose how and to whom to send it (mail, messenger, etc.). Otherwise the file never leaves the device. It contains the app settings (including your name, if you entered one), the course of the game (cards, tricks, scores), the app version, the device model and the iOS version. The developer uses a received file only to look into the problem.
