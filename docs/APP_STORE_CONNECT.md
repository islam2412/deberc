# Тексты для App Store Connect

Готовые формулировки: их можно копировать в App Store Connect как есть.

## Название приложения

Название должно быть уникальным во всём App Store. Под значком на телефоне всё равно будет написано просто «Деберц».

1. `Деберц: наши правила`
2. `Деберц по-домашнему`
3. `Деберц — карты с компьютером`

**Подзаголовок** (до 30 символов, для App Store): `Карточная игра с компьютером`

**Категория:** Игры → Карточные. Дополнительная — Настольные.

## TestFlight → Информация о тестировании

**Описание бета-версии**

```
Деберц — карточная игра на двоих или троих против компьютера, по нашим домашним правилам.

• Торговля за козырь в два круга, «обязы» после двух пересдач подряд
• Обмен козырной семёрки, четыре семёрки — +100 и пересдача
• Терц, полтинник и бэла; комбинации пишет только тот, у кого старше
• Байт и висячий байт, штрафы за каждый третий байт и за «голого»
• Партия до 701 очка, запись всех сдач
• Три уровня сложности и подсказка
• Все правила можно поменять в настройках

Игра работает без интернета, ничего не собирает и не требует регистрации.
```

**Что тестировать**

```
Сыграйте несколько партий вдвоём и втроём.
Проверьте, что всё идёт по вашим правилам: торговля, обязы, обмен семёрки, комбинации, байты и штрафы.
Если что-то не так — сделайте скриншот и отправьте отзыв через TestFlight: опишите, как должно быть по-вашему.
Подсказка: полный свод правил — в меню «Правила».
```

**Email для отзывов:** ваш адрес для отзывов.

**Ссылка на политику конфиденциальности:** `https://github.com/islam2412/deberc/blob/main/PRIVACY.md`

## Информация для проверки (Beta App Review)

- Требуется вход: **нет**.
- Контакты: имя, телефон, email того, кто отвечает на вопросы Apple.
- Заметки для проверяющего:

```
Offline card game (Deberc / Klaberjass family) played against computer opponents. No account, no network, no in-app purchases.
To start: tap "Новая партия" (New game). Rules are available in the menu "Правила" (Rules). All UI is in Russian.
```

## Для публикации в App Store (понадобится позже)

**Ключевые слова** (до 100 символов):

```
деберц,клабор,белот,карты,карточная игра,козырь,терц,бэла,взятки,офлайн
```

**Описание** — можно взять описание бета-версии.

**Конфиденциальность приложения** (App Privacy): «Данные не собираются» (Data Not Collected).

**Возрастной рейтинг:**

- на все вопросы — «Нет / Отсутствует»;
- «Имитация азартных игр» — «Нет»: в игре нет ставок и денег, это карточная игра на взятки.

**URL поддержки:** `https://github.com/islam2412/deberc/issues`

**Скриншоты:** нужны для App Store, для TestFlight не нужны. Их можно снять на симуляторе iPhone 6,9″ и iPad 13″, либо взять из артефактов CI: Actions → последний запуск CI → `screenshots-and-logs`.
